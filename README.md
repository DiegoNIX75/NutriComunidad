# NutriComunidad

**NutriComunidad** es una plataforma web orientada a mitigar el desperdicio de alimentos y combatir la inseguridad alimentaria mediante la conexión entre comercios, productores locales, organizaciones sociales y familias beneficiarias.

El sistema permite:
- **Gestión de Inventarios y Alertas:** Controlar existencias y emitir alertas sobre productos próximos a su fecha de consumo preferente para acelerar su distribución o donación oportuna.
- **Red de Distribución y Donaciones:** Administrar solicitudes, donaciones y entregas de alimentos entre comercios, organizaciones sociales y familias registradas.
- **Módulo de Recomendaciones:** Sugerir recetas y menús económicos adaptados a los ingredientes disponibles y a las preferencias o restricciones alimentarias de los usuarios.
- **Estadísticas y Reportes:** Generar métricas sobre alimentos recuperados, productos con mayor desperdicio y familias impactadas.

# Comandos

Para ejecutar y probar la aplicación web localmente, sigue estos sencillos pasos:

1. **Instalar dependencias (`npm install`)**
   - **¿Por qué se usa?:** Este comando descarga e instala todas las librerías, paquetes y módulos requeridos por el proyecto para poder ejecutarse correctamente.
   - **Cómo ocuparlo:** Abre la terminal en la carpeta raíz del proyecto y ejecuta:
     ```bash
     npm install
     ```

2. **Iniciar servidor de desarrollo (`npm run dev`)**
   - **¿Por qué se usa?:** Levanta un servidor local que compila la aplicación en tiempo real, permitiéndote ver y probar la página web en tu navegador mientras realizas cambios.
   - **Cómo ocuparlo:** Una vez instaladas las dependencias, ejecuta en la terminal:
     ```bash
     npm run dev
     ```
     *Posteriormente, abre el enlace que aparezca en la consola (por ejemplo, `http://localhost:5173` o `http://localhost:3000`) para interactuar con la plataforma.*
